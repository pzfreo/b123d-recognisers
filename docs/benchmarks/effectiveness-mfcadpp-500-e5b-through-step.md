## Effectiveness result

The bounded family returns 39 rectangular Through Step occurrences. Their 78 defining original
faces all carry MFCAD++ class 8: defining-face precision is 78/78 (100%), and defining-face recall
is 78/415 (18.80%). The corpus supplies no independent instance denominator, so no instance-recall
claim is made.

Every pre-existing physical-family count, mapped-class count, reconciliation-drop count,
diagnostic count, and class metric is unchanged from E5a. Enabling class 8 in the taxonomy also
makes its remaining false-negative faces visible in the global mismatch diagnostic; that aggregate
rises from 960 to 1,073 for this documented reason rather than because an existing family changed.

The optimized report is behavior-identical to the pre-optimization E5b run. After removing
environment, package metadata, aggregate runtime and per-model seconds, both canonical reports
have SHA-256 `5681f889f2237b0115a1eedf4c1170ab329e4653d123e6a8eded3996b4762d59`.

## Runtime result

Separate full runs on the shared host are contextual only: E5a took 223.50 seconds and optimized
E5b took 244.38 seconds. The isolated paired sentinel imports the same first 30 models once and
alternates complete inventory runs with Through Step discovery enabled and disabled. It found
three Through Steps, preserved every pre-existing output, and recorded 15.341 enabled seconds
versus 14.930 disabled seconds: ratio 1.0275, with a paired median delta of 0.0219 seconds.

## Scope and transfer

The predicate follows authored topology: two rectangular principal-plane regions, one complete
concave seam, both stock-envelope openings, an exactly empty removed prism, and one valid source
solid. It does not encode model IDs, class labels, fitted feature sizes, or corpus-derived
tolerances. Channels, pockets, slots, capped/partial runs, interrupted/tapered/curved walls,
non-principal runs and ambiguous ownership are explicit negatives.

MFInstSeg remains unavailable in the authenticated workspace, so this increment adds no transfer
score and does not treat MFCAD++ as blind evidence. The frozen MFInstSeg baseline remains the next
periodic transfer check when that corpus becomes available.

## ADR conformance

The final diff preserves ADRs 0001/0002/0003/0004/0007/0008/0011: one family module reads immutable
`FaceGraph` fact and writes through `EvidenceWriter`; the registry alone orchestrates it; evidence
names only original defining wall patches and is batch-validated against one valid solid before
issuance; the shared prism helper is policy-neutral; all geometric tolerances are existing named
kernel/tangent constants; and principal-axis permutations remain equivalent.
