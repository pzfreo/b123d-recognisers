## Runtime interpretation

The final full run recorded 222.429 seconds total, 0.421 seconds median and 0.808 seconds p95. The
older E3 report recorded 196.435, 0.364 and 0.723 seconds respectively on the shared host. Two
intermediate implementations exposed real eager-work problems and were rejected before review:
their totals were 407.799 and 464.495 seconds. The final consumer defers blend discovery until four
interrupted Pad wall roles exist and defers material-side certification until after that structural
gate.

Because separate full runs on a shared host do not isolate code cost, the committed paired sentinel
imported the first 30 models once and alternated the final consumer with the blend proposal route
disabled. Complete inventory outputs were identical. Enabled time was 14.228 seconds versus 13.920
seconds disabled (ratio 1.0221); the paired median delta was 0.0104 seconds. The per-model order,
timings and equality results are recorded in
[`pad-blend-performance-mfcadpp-30-5026261.json`](pad-blend-performance-mfcadpp-30-5026261.json),
generated by:

```bash
uv run python tools/benchmark_pad_blend.py mfcadpp \
  --root /app/workspaces-codex/datasets/mfcadpp/MFCAD++_dataset/step/test \
  --limit 30 \
  --output docs/benchmarks/pad-blend-performance-mfcadpp-30-5026261.json
```

The repository's absolute census check also ran unchanged: its minimum was 184.224 seconds against
the stale 109.651-second ceiling (`99.683 × 1.10`), so it failed rather than being waived. The
budget document already records later same-host census minima near 146 seconds and requires a
back-to-back ratio when the machine baseline has moved. The committed paired run imported the same
13 NIST and Gramel parts once, alternated enabled/disabled order by part, and asserted exact census
equality. Enabled total was 177.484 seconds versus 171.626 seconds disabled, ratio 1.0341; median
per-part times were 7.303 and 6.728 seconds, with a 0.0105-second paired median delta. That is within
the authoritative 1.10 census budget. Its per-part evidence is
[`pad-blend-performance-census-5026261.json`](pad-blend-performance-census-5026261.json), generated
by:

```bash
uv run python tools/benchmark_pad_blend.py census \
  --output docs/benchmarks/pad-blend-performance-census-5026261.json
```

The composite minimum was 3.564 seconds and is retained as a descriptive shared-host result,
consistent with that arm's documented instability.
